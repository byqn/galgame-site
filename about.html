关于本站

一个用纯 HTML / CSS / JavaScript 搭起来的静态站点。

这个站是做什么的

整理 Galgame 作品信息、攻略与资讯，方便按标签和关键词快速找到想玩的东西。所有数据都放在一个文件里，改内容不需要动页面代码，也不需要任何后端。

怎么更新内容

  • 作品数据：编辑 assets/js/data.js 里的 games 数组，复制一段已有条目改字段即可。
  • 攻略 / 资讯：编辑同一个文件的 posts 数组；body 里以 ## 开头的行会渲染成小标题，以 - 开头的行会渲染成列表。
  • 封面图：暂时用 CSS 渐变色块 + 文字占位，cover.hue 控制色调。以后要换真实封面，把图片放进 assets/img/，再改 common.js 里的 coverHtml() 即可。

技术说明

  • 纯静态：不需要构建、不需要 Node 服务，双击 index.html 就能看。
  • 数据用 <script> 引入而不是 fetch，所以用 file:// 直接打开也不会被浏览器的跨域策略拦住。
  • 页面：首页、资源库、作品详情、攻略列表、文章详情、关于，共 6 个页面。
  • 搜索、标签筛选、排序、分类全部在前端完成，数据量大到几千条也不会有压力。

部署到 GitHub Pages

  • 仓库 Settings → Pages → Source 选择 main 分支的 / (root)，保存后即可通过 https://byqn.github.io/galgame-site/ 访问。
  • 也可以直接部署到任意静态托管（Cloudflare Pages、Vercel、Netlify）。
