网站说明与常见问题

最后更新：2026/09/15

本站收录什么

整理 Galgame 的作品资料：标题、原题、制作会社、发售日期、平台、语言、标签、简介与截图。资料用于检索与归档，本站不存储、不提供任何游戏文件本体。

数据怎么更新

  • 作品与资源数据全部放在 assets/js/data.js，改这一个文件即可，不需要动页面。
  • 加作品：往 games 数组复制一段条目改字段；加补丁/教程：往 posts 数组里加。
  • body 里以 ## 开头的行渲染成小标题，以 - 开头的行渲染成列表。
  • 封面目前是渐变色块占位（cover.hue 控制色调、cover.glyph 是大字），换成真图见 README。

常见问题

  • 下载链接打不开？页面里所有下载地址都是占位符（#），请在 data.js 中替换。
  • 解压失败？分卷压缩包要全部下载完，用 7-Zip 或 Bandizip 解压，路径别带中文。
  • 游戏乱码或闪退？看《在 Windows 上正确安装日文 Galgame》与《游戏闪退排查清单》两篇教程。
  • 找不到想找的作品？用顶部搜索框，或到资源库按会社 / 标签 / 平台筛选。

技术说明

  • 纯静态站点：无构建、无后端、无依赖，双击 index.html 就能跑。
  • 数据用 <script> 引入而非 fetch，所以 file:// 直接打开也能正常渲染。
  • 搜索、筛选、分页全部在前端完成；筛选状态会写进 URL，方便分享。
  • 已启用 GitHub Pages，推送 main 分支即自动更新。
