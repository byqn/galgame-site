网站说明与常见问题

最后更新：2026/09/25

本站收录什么

整理 Galgame 的作品资料：标题、原题、制作会社、发售日期、平台、语言、标签、简介与截图；另外收录补丁、安装教程与资讯。所有内容以检索与归档为目的，本站不存储、不提供任何游戏文件本体。

内容怎么更新

  • 上传作品：打开 上传页 → 填资料 → 传封面（可选，会自动压缩成 1100px 宽的 JPEG）→ 也可以顺带传 游戏文件，访客就能在站内直接下载。
  • 发布资源 / 教程：同一个上传页切到「发布资源 / 教程」标签；正文支持 ## 小标题 与 - 列表项。
  • 修改或删除：打开 内容管理，可编辑或删除已上传的作品与资源（删除作品会一并清掉封面与站内文件）。
  • 所有数据保存在站点的 data/ 目录，改完刷新即生效；推送到 GitHub 后线上版本也会同步。

账号与邮箱验证

  • 注册需要邮箱验证码：10 分钟内有效，同一邮箱 60 秒只能发一次，用过即作废。
  • 忘记密码可在 登录页 切到「忘记密码」，用邮箱验证码重置；重置后该账号此前的登录状态会全部失效。
  • 密码用 scrypt 加盐哈希存储，服务器不保存明文；登录状态由本地 token 维持，有效期 30 天。
  • 默认是「本机模式」：验证码不会真的发邮件，而是直接显示在页面提示里。要发真邮件，在 data/mail.json 配置 SMTP 即可（详见 README）。

常见问题

  • 上传按钮点不动？上传、发布、管理都需要后端，只有本机服务器模式可用；静态托管（GitHub Pages）只能浏览。
  • 别人能调用我的上传接口吗？不能。所有写操作只接受 Host 为 localhost / 127.0.0.1 的请求 —— 即使站点通过 Cloudflare 隧道对公网开放也一样。
  • 站内下载的文件存在哪？服务器上的 files/ 目录。该目录已排除在版本库外，不会推到 GitHub。
  • 封面显示不出来？找不到封面图时会自动回退成程序化生成的渐变壁纸，不会出现破图。

技术说明

  • 前端纯静态：无构建、无框架、无 CDN 依赖，双击 index.html 也能跑。
  • 后端是单个 Node 文件（deploy/serve.js），提供静态托管、内容上传、账号与文件接口；除可选的 nodemailer 外无第三方依赖。
  • 数据用 <script> 引入而非 fetch，所以 file:// 直接打开也能正常渲染。
  • 已配置 GitHub Pages 与本机 Cloudflare 隧道两种访问方式。
