说明

  • 注册需要邮箱验证码：填好邮箱后点「获取验证码」，10 分钟内有效，同一邮箱 60 秒内只能发一次。
  • 没配置 SMTP 时是「本机模式」：不会真的发邮件，验证码会直接显示在页面提示里（仅 localhost 可见）。要发真邮件，在 data/mail.json 填好邮箱 SMTP 信息并执行 npm install nodemailer 即可。
  • 账号保存在你自己的服务器（data/users.json），密码用 scrypt 加盐哈希，邮箱与验证码也一并加密/限时存储。
  • 登录时用户名或邮箱都可以；登录状态通过本地 token 维持，有效期 30 天。
  • 注册 / 登录需要有后端：本机执行 node deploy/serve.js 8080 后访问 http://localhost:8080/login.html。静态托管的版本没有后端，无法注册登录。
