说明

  • 上传的作品会保存到站点的 data/games.json，封面图保存到 assets/img/covers/，保存后刷新即可在作品库看到。
  • 上传功能只在本地运行服务器时可用（node deploy/serve.js 8080 或 deploy\start-public.ps1）。部署到 GitHub Pages 的静态版本没有后端，只能浏览。
  • 出于安全考虑，上传接口只接受通过 localhost 发起的请求 —— 即使站点通过 Cloudflare 隧道对公网开放，别人也无法调用上传。
  • 想让上传的作品出现在公网版本上：本地保存后提交并推送仓库即可（图片和 JSON 都会一起进版本库）。
